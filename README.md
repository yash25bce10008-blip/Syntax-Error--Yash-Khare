# 🧭 Path Finder — Personalized AI Learning Platform

> **An AI-powered learning platform that creates personalized career roadmaps, adapts to your existing knowledge, recommends the best learning resources, and evaluates your progress using AI-generated quizzes.**

---

# ✨ Overview

Path Finder is an AI-powered personalized learning platform designed for students and developers who want a structured roadmap toward their dream career.

Instead of following generic courses, Path Finder creates a **custom learning roadmap** based on:

* 🎯 Career Goal
* 💻 Preferred Tech Stack
* 📚 Existing Knowledge
* ⏳ Target Deadline

Powered by **Google Gemini 2.0 Flash**, the platform dynamically generates personalized roadmaps, learning resources, quizzes, and daily challenges while tracking your progress in real time.

# ⚙️ How It Works

## 1. Authentication

Users securely sign up or log in.

* Passwords are hashed using **bcryptjs**
* Sessions are managed using **JWT**
* Authentication is handled by **NextAuth.js**

---

## 2. Onboarding

New users complete a four-step onboarding process:

* Choose Career Goal
* Select Preferred Tech Stack
* Enter Existing Skills
* Set Target Deadline

---

## 3. AI Roadmap Generation

The backend sends the user's preferences to **Google Gemini**, which returns a structured JSON roadmap tailored to the user's goals.

---

## 4. Data Persistence

The generated roadmap and user activity are stored in PostgreSQL.

Stored information includes:

* Roadmaps
* Progress
* Quiz Attempts
* Daily Questions
* Completed Topics

---

## 5. Interactive Dashboard

Users can:

* Browse their roadmap
* Complete milestones
* Access learning resources
* Attempt quizzes
* Solve the Question of the Day
* Monitor overall progress

# 💻 Getting Started

## Prerequisites

Before running the project, install:

* Node.js (v18 or later)
* PostgreSQL
* Git
* Google Gemini API Key

---

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/path-finder.git

cd path-finder
```

---

## 2. Install Dependencies

```bash
npm install
```

---

## 3. Setup PostgreSQL Database

Create a PostgreSQL database, for example:

```text
career_pipeline
```

Execute the following SQL schema:

```sql
CREATE TABLE IF NOT EXISTS student (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(255),
  password_hash TEXT NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS student_topic_progress (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_id UUID NOT NULL REFERENCES student(id) ON DELETE CASCADE,
  topic_id UUID NOT NULL REFERENCES topic(id) ON DELETE CASCADE,
  status VARCHAR(20) NOT NULL DEFAULT 'todo',
  completed_at TIMESTAMPTZ,
  UNIQUE(student_id, topic_id)
);

CREATE TABLE IF NOT EXISTS student_roadmap (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_id UUID NOT NULL REFERENCES student(id) ON DELETE CASCADE,
  career_id UUID NOT NULL REFERENCES career(id) ON DELETE CASCADE,
  career_title VARCHAR(255),
  known_topics JSONB DEFAULT '[]',
  deadline_weeks INTEGER,
  stack_choice JSONB,
  roadmap_data JSONB,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS quiz_attempt (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_id UUID NOT NULL REFERENCES student(id) ON DELETE CASCADE,
  topic_id UUID NOT NULL REFERENCES topic(id) ON DELETE CASCADE,
  score SMALLINT,
  total SMALLINT DEFAULT 5,
  answers JSONB,
  attempted_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS daily_question (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  date_str VARCHAR(10) UNIQUE NOT NULL,
  question JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS student_daily_question (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_id UUID NOT NULL REFERENCES student(id) ON DELETE CASCADE,
  question_id UUID NOT NULL REFERENCES daily_question(id) ON DELETE CASCADE,
  solved_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(student_id, question_id)
);
```

> **Note:** The `career` and `topic` tables are expected to be created during the initial database seeding.

---

## 4. Configure Environment Variables

Create a file named:

```text
.env.local
```

Add the following variables:

```env
# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key

# NextAuth
NEXTAUTH_SECRET=your_super_secret

NEXTAUTH_URL=http://localhost:3000
```

---

## 5. Run the Development Server

```bash
npm run dev
```

Then open:

```
http://localhost:3000
```
